# Evidence for M00-L01 — How to learn and check readiness

Checked 2026-11-11. The diagnostic and study schedules are original Academy examples. The cited experiments measure retention under their experimental conditions.

| ID | Claim | Publisher, version and section | Scope and confidence |
|---|---|---|---|
| R1 | A request can take effect even when the client receives no response. Automatic retry of a non-idempotent method requires knowledge that the operation is idempotent or evidence that the original request was never applied. | IETF, RFC 9110 (2022), [§6.2](https://www.rfc-editor.org/rfc/rfc9110.html#section-6.2) and [§9.2.2](https://www.rfc-editor.org/rfc/rfc9110.html#section-9.2.2). | Verified. The example endpoint's behavior depends on its application contract. |
| R2 | A PostgreSQL transaction block commits its changes as a unit or cancels them on rollback. A retry in a new transaction needs a business invariant that prevents a second durable effect. | PostgreSQL Global Development Group, PostgreSQL 18, [§3.4 Transactions](https://www.postgresql.org/docs/18/tutorial-transactions.html). | Verified for the transaction block. The retry requirement follows from the hypothetical service's invariant. |
| R3 | A hash lookup chooses a bucket and resolves collisions by checking candidate keys. Good distribution is a condition for fast expected lookup. | Sedgewick and Wayne, *Algorithms*, 4th ed., [§3.4 lecture, Hashing: basic plan](https://algs4.cs.princeton.edu/lectures/keynote/34HashTables-2x2.pdf). Oracle, Java SE 21, [HashMap class description](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/HashMap.html). | Verified. Use an abstract chained table in the example. A process-local table is scoped to its process. |
| R4 | RabbitMQ can requeue a manually acknowledged delivery if its channel closes before the broker receives the acknowledgement. A worker that commits before that failure can see the delivery again. | RabbitMQ 4.2, [Consumer Acknowledgements and Publisher Confirms, When Consumers Fail or Lose Connection](https://www.rabbitmq.com/docs/4.2/confirms#automatic-requeueing) and [Reliability Guide, Data Safety on the Consumer Side](https://www.rabbitmq.com/docs/4.2/reliability#consumer). | Verified for AMQP 0-9-1 manual acknowledgement. The example follows from the stated failure order. |
| R5 | Recall during practice improved delayed retention in the cited studies. The effect of spacing depends on the time before the later test. | Karpicke and Roediger (2007), [Repeated retrieval during learning, abstract and Experiments 1–2](https://learninglab.psych.purdue.edu/downloads/2007/2007_Karpicke_Roediger_JML.pdf). Optimal spacing for design transfer remains unresolved. The example schedules are instructional choices. |
