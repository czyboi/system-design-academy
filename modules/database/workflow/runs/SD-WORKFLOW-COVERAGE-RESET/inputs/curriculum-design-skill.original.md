# Curriculum Design

1. Identify target learner, entry knowledge, target capability, and scope boundaries.
2. Build a topic inventory from the System Design Primer and approved additional sources.
3. Add necessary prerequisites; label additions as new material, not Primer-derived content.
4. Build a dependency graph and sequence concepts from problem → mechanism → trade-off → applied design.
5. Write measurable outcomes using observable verbs: calculate, compare, explain, choose, diagnose, design, defend.
6. Map every outcome to at least one assessment item.
7. Separate core topics, optional deep dives, and vendor-specific labs.
8. Find overlap and cross-reference instead of repeating large explanations.
9. Estimate learner effort and label estimates provisional.

## Output
Return module scope/non-goals, lesson sequence/prerequisites/time, dependency map, outcome-to-assessment matrix, gaps, overlaps, and assumptions.

Do not author full lessons or declare technical claims verified.
