# M01-L01 technical and provenance review

## Findings

- **M01-L01-T01 · minor · open.** [Companion exercise, inputs and sample solution](../../../../assessments/M01-L01.md#ex-1--size-a-30-day-news-activity-feed), lines 20 and 29. “Normal-traffic one-hour interval” leaves the write rate implicit. The sample solution uses 5 writes/s, which is the daily average. A valid day could instead have 6 writes/s during the selected hour and yield a different distinct payload while preserving the daily total. State that the interval runs at the average write rate, or accept a result derived from a different explicitly assumed rate in the rubric. [Lesson's two-hour model](../../../../lessons/M01-L01.md#budget-storage-bandwidth-and-the-working-set) · [Denning, §3 and Figure 2](https://denninginstitute.com/pjd/PUBS/WSModel_1968.pdf#page=4).
- **M01-L01-T02 · note · open.** [Lesson, storage and bandwidth](../../../../lessons/M01-L01.md#budget-storage-bandwidth-and-the-working-set), lines 21 and 46. The 0.32 Mbit/s ingress estimate uses the 1,000 B stored payload as the API write payload. The numbers agree under that representation assumption. State the API write payload and stored payload separately, even when both are 1,000 B, so an engineer can carry the method over to ingestion that compresses, transforms or enriches records. [NIST, byte and bit definitions](https://physics.nist.gov/cuu/Units/binary.html).
