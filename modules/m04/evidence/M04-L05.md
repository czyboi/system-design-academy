# Source evidence for M04-L05

Checked 2026-11-13. Confidence is verified for the scoped claims below. Worked scenarios and design calculations are original and use illustrative assumptions.

| Claim | Supported mechanism | Primary evidence | Limits |
| --- | --- | --- | --- |
| Plan and workload | PostgreSQL EXPLAIN reports estimated plan costs. ANALYZE executes the statement, reports measured row/time values and exposes loops. pg_stat_statements aggregates statement statistics. | [PostgreSQL 18 §14.1](https://www.postgresql.org/docs/18/using-explain.html), [Appendix F.32](https://www.postgresql.org/docs/18/pgstatstatements.html) | Example plans are hypothetical. Per-loop values and the end-to-end workload must be distinguished. |
| Types | PostgreSQL documents blank-padded CHAR, VARCHAR/TEXT and exact NUMERIC with scale/precision controls. | [PostgreSQL 18 §8.3](https://www.postgresql.org/docs/18/datatype-character.html), [§8.1](https://www.postgresql.org/docs/18/datatype-numeric.html) | Choose domain limits and currency rounding explicitly. Type behavior and performance are product scoped. |
| Access and load | Leading equality in B-tree access narrows scans. Predicate-driven partition pruning excludes irrelevant partitions. Building indexes after an isolated initial bulk load can be cheaper than incremental maintenance. | [PostgreSQL 18 §11.3](https://www.postgresql.org/docs/18/indexes-multicolumn.html), [§5.12](https://www.postgresql.org/docs/18/ddl-partitioning.html#DDL-PARTITION-PRUNING), [§14.4](https://www.postgresql.org/docs/18/populate.html) | Live index removal can remove constraint enforcement and degrade reads. The partitioning example is within one database. |
| Historical cache | MySQL 5.7 had a server-side result cache with table-dependent invalidation. MySQL 8.0 removed it. | [Oracle, MySQL 5.7.44 query cache implementation](https://github.com/mysql/mysql-server/blob/mysql-5.7.44/sql/sql_cache.cc), [MySQL 8.0 Reference Manual, features removed](https://dev.mysql.com/doc/refman/8.0/en/mysql-nutshell.html#mysql-nutshell-removals) | Application result caching has an application-defined key, invalidation and freshness contract. |
