## Independently verified claims and interleavings

- [RFC 4648 §§4–5](https://www.rfc-editor.org/rfc/rfc4648.html#section-5) supports the standard Base64/base64url alphabet distinction. [RFC 3986 §§2.3–2.4 and 7.3](https://www.rfc-editor.org/rfc/rfc3986.html#section-2.3) supports unreserved characters and parsing components before decoding delimiters. Base62, 10-character randomness and unique insertion are declared application choices. Random representation does not create authorization; [OWASP IDOR](https://cheatsheetseries.owasp.org/cheatsheets/Insecure_Direct_Object_Reference_Prevention_Cheat_Sheet.html#identifier-complexity) supports that distinction.
- The create path claims the caller-scoped retry key and stable ID before downstream work; pending metadata is unreadable, and publication follows a successful immutable-object write/visibility check. Lost responses reuse the operation receipt, conflicting inputs reject, and uniqueness collisions do not overwrite another resource. Those contracts are coherent at this design level. The text does not falsely make the two stores one transaction. [AWS S3 consistency](https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html#ConsistencyModel) supports its named object-operation scope, while external metadata publication remains application work.
- Tombstones precede physical cleanup, versioned immutable identity prevents an old cleanup deleting a newly reused payload, and stale fills must not restore old active state. These safeguards address stored-state races; T1 concerns the separate *response admission* boundary. Private access/presigned capabilities must preserve that distinction.
- The HTTP invalidation discussion is correctly limited to an intermediary seeing a non-error unsafe response; it does not promise global purge. [RFC 9111 §4.4](https://www.rfc-editor.org/rfc/rfc9111.html#section-4.4). Monthly analytics explicitly deduplicates event IDs before `(year-month, code)` aggregation; h1 yields January 1 and h2+h3 February 2. [Original MapReduce publication](https://research.google/pubs/mapreduce-simplified-data-processing-on-large-clusters/) supports key grouping/reduction, not application deduplication or receipt guarantees.
- The lesson defines a five-minute original-operation cohort, 500 ms client receipt, retry identity and an explicit correct-denial class; fast errors for active content are not success. The exercise sample preserves those boundaries. Rubric quality is separately reviewed by pedagogy; the technical classification must be made consistent with T1's chosen admission policy.
