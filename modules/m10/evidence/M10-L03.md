Robots Exclusion Protocol provides cooperative crawler user-agent and allow/disallow path matching; is not access control. | IETF [RFC 9309 §§1, 2.2.2, 2.3 and 3](https://www.rfc-editor.org/rfc/rfc9309.html#section-2.2.2), opened 2026-11-16. | Verifies normative robots behavior and security caveat. | C5. URI normalization must respect component syntax and equivalence. | IETF [RFC 3986 §6](https://www.rfc-editor.org/rfc/rfc3986.html#section-6), opened 2026-11-16. | App-specific query normalization remains unspecified by RFC; do not incorrectly drop meaningful URL parameters. |
