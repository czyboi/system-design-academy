# Source evidence for M07-L03

Checked 2026-11-14. The exhibit projection, partitions and offsets are original illustrative records.

| Claim | Primary evidence | Applicability |
| --- | --- | --- |
| C1. The original Kafka design uses append-only partitions, consumer-driven reads and offsets. | Kreps, Narkhede and Rao, NetDB 2011 [Kafka: a Distributed Messaging System for Log Processing, §3](https://www.microsoft.com/en-us/research/wp-content/uploads/2017/09/Kafka.pdf). | Verified historical design. No historical benchmark or implementation limit is inherited by current Kafka. |
| C2. Classic consumer groups assign partitions among members and each group maintains its own positions. Records within a partition have offsets. Replication and acknowledgement configuration affect durability. | Apache Kafka 4.2 [Design, The Consumer, Message Delivery Semantics, Replication and Log Compaction](https://kafka.apache.org/42/design/design/). | Verified for ordinary Kafka consumer groups and documented semantics. External projection updates still require application commit/replay logic. |
| C3. Kafka 4.2 can delete old segments as configured or compact a keyed log. Tombstones have a retention window. | Apache Kafka 4.2 [Topic Configs, cleanup.policy, retention.ms, retention.bytes and delete.retention.ms](https://kafka.apache.org/42/configuration/topic-configs/), [Log Compaction](https://kafka.apache.org/42/design/design/#log-compaction). | Verified documented mechanisms. Check actual earliest offsets and snapshot consistency before replay. |
| C4. A transactional outbox persists event intent with source changes. Relay failures may duplicate messages. | AWS Prescriptive Guidance [Transactional outbox, Issues and considerations](https://docs.aws.amazon.com/prescriptive-guidance/latest/cloud-design-patterns/transactional-outbox.html#issues-and-considerations). | Verified design pattern. Event identity, source version, ordering and repair are application contracts. |
| C5. A missing or out-of-range consumer offset can trigger configured reset behavior, including an error. | Apache Kafka 4.2 [Consumer Configs, auto.offset.reset](https://kafka.apache.org/42/configuration/consumer-configs/). | Verified for the Kafka consumer. Offset reset cannot reconstruct data missing from a snapshot or retained log. |
