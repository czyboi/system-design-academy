# Decision Log

## 2026-11-09 — Start with a private repository

**Decision:** Keep `system-design-academy` private during development.

**Reason:** The project is a working draft. This reduces accidental publication while source provenance, third-party asset rights, and technical QA are being reviewed. Public release can be considered later.

## 2026-11-09 — Markdown as canonical content format

**Decision:** Store lessons, rubrics, prompts, diagrams-as-code, and provenance in Markdown/CSV/JSON.

**Reason:** These formats are versionable, portable, reviewable, and convenient for AI tooling.

## 2026-11-09 — Human approval required

**Decision:** AI can prepare review-ready drafts but cannot publish learner-facing content.

**Reason:** Technical and legal correctness require accountable human review.
